Four independent specialized subagent tracks completed a line-by-line audit across API, settings, loader, layout engine, conversion pipeline, performance, memory allocation, concurrency, and Go code style. Below is the executive roadmap to achieve a perfect 10/10 rating.

Why the Rating Was Previously Capped at 7.5

  • Source-Only Verification Boundary: No Go commands (`go test`, `go bench`, `golangci-lint`, race detector) were run, placing an upper ceiling on confidence scores.
  • Untyped Tagged Union Request: `convert.Request` co-located PDF and Image settings in a single struct, permitting unrepresentable invalid states.
  • Anti-Pattern Deferred Loader Error (`initErr`): `NewLoader` stored initialization errors in `initErr` rather than failing fast in constructor.
  • Discarded Context on I/O: Local file loading ignored `ctx.Err()`, and functions used `context.Background()` fallbacks.
  • DOM Ancestor Severing: Synthetic page island DOMs severed parent chains and left dangling heading pointers.
  • Parameter Bloat & Broad Suppressions: Core functions accepted 7–10 parameters, and `hf.go` suppressed cyclomatic complexity linters with broad `//nolint` comments.
  • Package-Level Mutable State & Concurrency Risks: Package `var` maps (`namedColorTable`, `flagTable`) and un-synchronized structures (`pdf.Registry`, `pdf.Document`).

5 Phase Execution Plan to 10/10

PhaseFocus AreaKey Architectural Remediation
Phase 1 Type Safety & Concurrency Core Sealed `Request` interface (`PDFRequest` vs `ImageRequest`), `sync.RWMutex` on `pdf.Document` & `pdf.Registry`, replace `var` maps with `sync.OnceValue`.
Phase 2 Loader & Context Enforcement Fail-fast `NewLoader`, pre-I/O `ctx.Err()` checks, `HardMaxBodyCap` (1 GiB) security ceiling, canonical `errs.ErrNilContext`.
Phase 3 Layout Engine & DOM Integrity Encapsulate parameter lists (`pagePainter`, `PrepareParams`), atomic DOM child creation, build-time HF link resolution, pristine TOC result isolation.
Phase 4 Performance & Memory Allocation Recycle `flateBytes` buffer capacity, `sync.Pool` for supersampled pixel buffers, NaN/Inf SVG float bounds check, deterministic time pinning.
Phase 5 Lint Elimination & Certification Remove all broad `//nolint` comments, execute full test suite, benchmark suite, race detector, and linter to certify 10/10 perfection.
