## Cross-package contracts (implement exactly these)

1. **Engine seam (P1-1).** `internal/convert` gains:
   `type Request struct { Global settings.PdfGlobal; Image *settings.ImageGlobal; Objects []settings.PdfObject; Output io.Writer }`
   and `func Run(ctx context.Context, req *Request, log io.Writer, progress func(phase string, pct int)) error`.
   Keep `RunPDFContext(ctx, *cli.Command, ...)` and `RunPDF` as thin adapters building Request.
   `internal/imageout` gains a matching `Run(ctx, *Request, log)`; its old `Run(ctx, *cli.Command, ...)` stays as adapter. Wave 2 migrates `api.go` and `cmd/*` mains.
2. **Stylesheet gatherer (P2-01/P2-14).** `internal/convert` exports `CollectSheets(ctx, loader, root, base, lp, opts SheetOptions, log) []*css.Stylesheet`; `internal/imageout` (wave 2) becomes a caller and deletes its twin.
3. **LengthToPt (P3-03).** `internal/css` exports `func LengthToPt(v Length, basePt float64) float64`; `internal/layout` calls it (no copies).
4. **Paint semantics (P5-01).** `internal/layout/paint.go` owns the canonical op-semantics decisions (fake-bold gate incl. CJK-Latin policy, alpha, stroke). `internal/convert/hf.go` and `internal/imageout` consume it. One source of truth.
5. **Outline (P2-02/P2-05).** `internal/outline` owns `Heading`, `SortHeadings`, and the section lookup; `internal/convert` only consumes. Heading is flattened once, never mutated after sort.
6. **Loader policy (P2-07).** `settings.LoadGlobal` gains `Allow []string` and `EnableLocalFileAccess bool`; `load.NewLoader(g)` applies everything; callers stop poking fields.
7. **Log protocol (P6-01).** `internal/line` package (created by fix-root-api): `type Severity; Emit(w io.Writer, sev Severity, format string, args ...); SeverityOf(string)`. convert (fix-convert) and imageout (wave 2) switch their `fmt.Fprintf(log, "warning: …")` sites to `line.Emit`.
8. **In-memory HTML (P2-04).** `api.go`/`load` gain an explicit source kind: `func (c *Converter) AddHTML(page []byte, baseURL string)`; classification no longer guesses via `IsHTML` substring for the library path. Full wiring in wave 2.
9. **Grayscale (P5-03).** Implement the paint-time grayscale seam in pdf.Document (it must honor ColorMode=Grayscale) or remove the dead setter. Decide + log which.
10. **Font embed mode (P5-06).** One embed pipeline `ensureFont(...)` with a `simple bool` mode switch; units→1000-em conversion one shape. Keep base-14 path untouched.
